Banner → PNG

Aşağıdaki düğme, banner’ı GitHub’ın istediği 1280×640 PNG olarak indirir. İnternet bağlantısı gerekmez; dönüştürme tarayıcınızda yapılır.

İndirdiğiniz dosyayı GitHub’da Settings → General → Social preview altına yükleyin. GitHub bu alanda yalnızca PNG, JPG veya GIF kabul eder ve dosya 1 MB’ın altında olmalıdır — bu dosya yaklaşık 60–120 KB olur.
